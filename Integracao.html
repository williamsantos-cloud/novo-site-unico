Início/Integração

Do primeiro prompt ao primeiro token.

O jeito mais rápido é conectar o MCP ao seu agente. Se preferir integrar à mão, o SDK e a API seguem o caminho tradicional, e a documentação traz cada detalhe.

Conectar pelo MCP Documentação →
01 · MCPrecomendado

Seu agente faz a integração. Você revisa.

Conecte o MCP da Unico ao agente que você já usa. Ele lê o seu código, entende onde fica o cadastro e escreve a captura, a chamada e o tratamento da resposta.

  1. 01Conecte. Escolha onde você programa: no editor abre direto, no terminal é um comando.
  2. 02Peça. Em linguagem natural, do jeito que pediria a alguém do time.
  3. 03Revise. O agente abre a mudança no seu código, com os 10.000 primeiros tokens já liberados para testar.

03 · API

Uma chamada. Qualquer linguagem.

Já tem a sua própria captura? Mande a selfie para a API e receba o token. A resposta é a mesma do SDK e do MCP.

A mesma chamada em cada momento do produto. Muda só o que você faz com a resposta.

jaCadastrada → bloquear
CadastroUma pessoa, uma conta. A segunda tentativa vai para o login.
token igual → entrar
LoginEntrar com o rosto, sem senha e sem código por SMS.
token igual → liberar
RecuperaçãoPerdeu o celular? O rosto devolve a conta para o dono.
token diferente → barrar
Ação sensívelTrocar e-mail, sacar, transferir: só com o rosto do titular.
